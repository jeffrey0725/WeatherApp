# Status and progress

Last updated: 2026-11-01 01:21:02 HKT (UTC+08:00)

Current stage: a working Hong Kong weather MVP with a regional weather explorer offering map/list views and Near me weather, a past-hour rainfall Map/List dashboard with station details, a sunrise/sunset card, a Moon & tides screen (moonrise/moonset and predicted tides for a chosen HKO tide station), an interactive nine-day forecast chart, and an XcodeGen build definition. The failed-warning-refresh display issue is addressed in code and regression tests. Broader fresh-fetch/distribution issues and iOS runtime validation remain open.
